Panel central de aplicaciones, herramientas y software desarrollado por **novatechlabs**, diseñado con estética oscura de alto contraste (negro `#0B0B0D`, texto blanco `#FFFFFF` y acentos amarillo-naranja `#FFB800` → `#FF6A00`).

## Proyecto Principal: StockFacil Business
Sistema de gestión comercial para kioscos y comercios orientado a operación real diaria:
- **Base de datos 100% local en el equipo:** los datos del comercio permanecen en la PC o notebook del cliente con respaldos locales.
- **Caja rápida:** carga por código de barras o nombre, atajos de teclado (`F2`, `Enter`, `F4`, `F8`), cálculo de vuelto y comprobantes imprimibles.
- **Cuenta corriente:** control de límite de crédito, entregas/pagos parciales, historial de movimientos y ajuste de saldo.
- **Stock, costos y arqueo:** márgenes porcentuales, control de vencimientos, aumento masivo protegido por PIN y arqueo diario con gastos/retiros.
